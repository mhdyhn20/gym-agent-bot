# RokhFit

نسخه‌ی ۲ اپلیکیشن آفلاین برنامه‌ی تمرینی فارسی برای اندروید، با ثبت ست‌ها و مربی هوشمند آفلاین.

- شناسه: `app.rokh.fitness`
- نسخه: `2.0.0`
- حداقل اندروید: Android 7 (API 24)
- بدون API خارجی برای قابلیت‌های مربی
- ذخیره‌سازی محلی با localStorage

در نسخه‌ی ۲ ثبت وزنه/تکرار هر ست، سابقه‌ی عملکرد هر حرکت، پیشنهاد پیشرفت و صفحه‌ی تحلیل هفتگی اضافه شده است.
