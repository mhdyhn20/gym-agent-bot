# RokhFit

نسخه‌ی فعلی رخ فیت یک اپ تمرینی فارسی، آفلاین و شخصی‌سازی‌شده برای اندروید است.

## نسخه 2
- بازگشت راهنماهای کامل حرکات از نسخه‌ی اصلی
- دموی دو-فریمی شروع/پایان برای حرکات
- راهنمای مرحله‌ای، دامنه حرکت، تنظیمات و عضلات
- ثبت ست‌ها با وزنه و تکرار
- ذخیره خودکار جلسه‌ی نیمه‌تمام
- تاریخ‌گذاری محلی دستگاه
- تایمر استراحت مقاوم‌تر در برابر رفتن اپ به پس‌زمینه
- پیشنهاد پیشرفت مبتنی بر سابقه‌ی خود کاربر
- UI موبایل‌اول با یک مسیر واضح از «امروز → برنامه → آموزش حرکت → ثبت ست»

داده‌های تمرین و تنظیمات در خود دستگاه نگهداری می‌شوند و موتور مربی اولیه به API خارجی نیاز ندارد.
